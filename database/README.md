SQLite is built automatically by `python main.py` and when Run analysis is submitted in the dashboard. The local `customers.db` is intentionally excluded from Git because uploaded customer records should not be published. Tables: datasets, customers, transactions, runs, cluster_results, recommendations. Dataset/run IDs retain history rather than overwrite earlier customer sets. Delete the database only if you intend to discard this local history.

The login creates a separate local `auth.db` with `users` and `auth_sessions`. It stores salted password hashes and session-token hashes, not plaintext passwords or raw tokens. This database is excluded from Git and the portable package. First-use bootstrap defaults to admin/admin123 for the college demonstration; the README explains environment-based bootstrap configuration and session limits.
